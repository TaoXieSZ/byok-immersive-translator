## MODIFIED Requirements

### Requirement: 提取适合翻译的可见文本块
扩展 MUST 按 DOM 顺序识别可见的语义文本块，并 MUST 排除脚本、样式、表单控件、独立代码块、可编辑区域、纯标点、不可见内容和扩展自身插入的节点。父子候选块 MUST 去重，避免同一文本重复提交。候选块内部存在受支持的行内语义时，扩展 SHALL 建立不含任意 HTML、样式或事件属性的版本化格式描述。

#### Scenario: 普通文章页面
- **WHEN** 页面包含标题、段落、列表项和引用
- **THEN** 扩展按阅读顺序生成不重复且带稳定 ID 的候选块

#### Scenario: 页面包含不可翻译内容
- **WHEN** 页面同时包含脚本、样式、独立代码块、输入框和隐藏文本
- **THEN** 这些内容不进入任何远端翻译请求

#### Scenario: 页面没有候选文本
- **WHEN** 当前页面不存在符合条件的可见文本块
- **THEN** 扩展保持页面不变并显示没有可翻译内容

#### Scenario: 段落包含行内格式
- **WHEN** 一个候选段落包含粗体、斜体、行内代码、键盘输入、标记、上下标、显式换行或链接
- **THEN** 扩展保留完整可翻译文本，并为受支持元素建立块内稳定且可验证的格式描述

#### Scenario: 段落包含不支持的行内容器
- **WHEN** 候选段落包含站点自定义元素、任意 class、内联样式或事件属性
- **THEN** 扩展只提取其可见文本且不把这些标签、属性或行为加入格式描述

### Requirement: 分批请求并严格映射译文
扩展 SHALL 按条目数和字符预算对候选块分批，并 MUST 要求 provider 返回 block ID 到译文字符串的映射。格式化块的译文字符串 SHALL 使用扩展定义的不透明格式标记引用当前块的可信格式描述。系统 MUST 在渲染和缓存前验证响应仅包含当前批次 ID、每个译文为字符串，并独立验证格式标记的版本、ID、唯一性、配对和嵌套关系。

#### Scenario: 批次响应完整
- **WHEN** provider 返回当前批次所有 block ID 的有效译文
- **THEN** 扩展把每个译文渲染到对应原文块，不受响应字段顺序影响

#### Scenario: 批次响应缺项或格式错误
- **WHEN** provider 返回未知 ID、缺少预期 ID或无法解析的响应
- **THEN** 扩展不猜测映射，最多重试该批次一次，并在再次失败后把相关块标记为失败

#### Scenario: 某一批请求失败
- **WHEN** 一个批次遇到网络、认证、限流或服务端错误
- **THEN** 其他成功批次保持已翻译状态，失败批次保持原文并可单独重试

#### Scenario: 格式标记被移动且结构有效
- **WHEN** provider 按目标语言语序移动完整格式标记对且所有标记通过验证
- **THEN** 扩展按译文顺序重建对应格式而不要求片段保持原文位置

#### Scenario: 格式标记无效
- **WHEN** provider 遗漏、重复、改写或错误嵌套格式标记但 block 映射和译文字符串仍有效
- **THEN** 扩展不得猜测格式归属，并 SHALL 清除保留标记后把该结果安全降级为纯文本译文

### Requirement: 保留原文并安全插入译文
扩展 MUST 保留原始 DOM 内容，并 SHALL 在对应文本块后插入带扩展标记的译文容器。译文容器 MAY 使用扩展从可信原文格式描述重建的 `strong`、`em`、`code`、`kbd`、`mark`、`sub`、`sup`、`br` 和安全 `a` 元素；普通文本和任何 provider 输出 MUST 通过 DOM 文本节点处理，不得把模型提供的 HTML、属性、URL、样式或脚本作为页面结构执行。

#### Scenario: 渲染成功译文
- **WHEN** 一个文本块收到格式标记完整且通过验证的译文
- **THEN** 原文保持不变，译文紧随其后，并按目标语言顺序保留对应的粗体、斜体、行内代码或其他受支持语义

#### Scenario: 译文包含 HTML 字符串
- **WHEN** provider 输出包含标签、Markdown 或脚本样式的字符
- **THEN** 页面将其显示为普通文本且不创建模型指定的元素、属性或可执行节点

#### Scenario: 译文包含原文链接
- **WHEN** 通过验证的格式结果引用原文中的安全 HTTP、HTTPS、mailto 或同页 fragment 链接
- **THEN** 扩展仅使用原始 DOM 保存的目标地址重建链接，并为新窗口链接补充安全 rel 属性

#### Scenario: 原文链接使用危险 scheme
- **WHEN** 原始格式描述中的链接无法解析或使用不允许的 URL scheme
- **THEN** 扩展保留对应译文文本但不创建可点击链接

#### Scenario: 格式无法可靠恢复
- **WHEN** 候选块包含超出限制的格式结构或最终格式标记未通过验证
- **THEN** 扩展使用单个纯文本译文结果且不修改、移动或克隆原始页面节点

#### Scenario: 重复收到同一结果
- **WHEN** 同一 session 的同一 block ID 因重试或迟到响应再次到达
- **THEN** 扩展保持单个译文容器，不重复插入格式节点或纯文本节点

### Requirement: 页面内容最小化传输
扩展 MUST 只向当前选中的 provider 发送完成翻译所需的候选文本、稳定 ID、目标语言、翻译指令和不含页面属性的格式标记，MUST NOT 附带完整页面 HTML、Cookie、表单值、浏览历史、链接地址、任意 DOM 属性或页面样式。

#### Scenario: 构造远端翻译请求
- **WHEN** Service Worker 接收一个有效文本批次
- **THEN** 请求载荷只包含候选文本、稳定 ID、目标语言、翻译指令和必要的格式标记，不包含完整 DOM、Cookie、表单值、浏览历史或 API Key 之外的浏览器数据

#### Scenario: 格式化文本包含链接
- **WHEN** 候选文本中的受支持格式包含一个链接
- **THEN** Provider 只接收该链接的可见文本和不透明格式标记，链接地址与原始属性保留在 Content Script 本地
