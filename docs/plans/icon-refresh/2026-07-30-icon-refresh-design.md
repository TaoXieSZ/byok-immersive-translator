# B2 + A3 图标落地设计

## 已确认选择

- 扩展主图标使用 **B2 对译双页**。
- 页面悬浮按钮使用 **A3 单气泡分栏**。
- 保留现有海军蓝 `#172B3D`、珊瑚红 `#D95B40`、米白 `#F5EFE4` 和暖白 `#FFFDF8`。

## 使用边界

### B2 主品牌

B2 用于 Manifest 扩展图标、浏览器工具栏和悬浮面板标题标记。图形由左右两个页面/气泡组成，左侧代表原文，右侧代表译文，下方的单向交换桥强调翻译过程。

主图标不得依赖系统字体或文本 glyph。所有组成部分使用确定性的 SVG path、rect 和 stroke；PNG 从同一 SVG 导出 16、32、48、128px，避免各尺寸漂移。

### A3 页面动作

A3 只用于页面右下角悬浮按钮。单个气泡左右分栏，左侧使用抽象“文”笔画，右侧使用抽象 “A” 笔画，表达“点击即翻译”。它不替代主品牌，不写入 Manifest。

悬浮按钮已有的进度环、计数徽标、hover、focus、翻译中和再次点击移除翻译行为保持不变；只替换内部 SVG。

## 验收

- Manifest 四种 PNG 尺寸与声明一致，均来自 B2 SVG。
- 浏览器浅色、深色工具栏下 16/32px 仍可辨认左右双页。
- 悬浮按钮在真实文章中显示 A3，面板标题显示 B2。
- 图标替换不改变权限、翻译协议、按钮语义或交互状态。
- `npm run verify`、`git diff --check` 和 BrowserOS 真实页面视觉检查通过。
