## Why

当前译文只能使用扩展预设字体，用户无法根据阅读习惯、中文显示效果或技术文章中的代码风格调整字体。支持选择 Maple Mono 等本机字体，可以提升双语页面的辨识度和长文阅读体验，同时避免改变原网站内容。

## What Changes

- 在扩展设置中增加“译文字体”，提供默认字体、Maple Mono 等常用预设以及自定义字体名称。
- 只把所选字体应用于扩展插入的译文容器；原文、页面控件和原网站 CSS 保持不变。
- 实时预览中英文、数字、标点和行内代码效果，并在字体不可用时显示明确的回退结果。
- 将字体偏好保存在当前设备的扩展本地存储，并让已打开页面在设置变化后更新现有译文，无需重新请求翻译。
- 对自定义字体名称进行长度、字符和条目数量限制；不接受任意 CSS 声明、远程字体 URL、`@font-face` 或页面样式注入。
- 保留译文中 `code`、`kbd` 等语义元素的独立等宽字体策略，并允许它们优先使用所选 Maple Mono 字体栈。

## Capabilities

### New Capabilities

- `translation-appearance-customization`: 管理、验证、预览和应用仅作用于译文的本机字体偏好，并在字体缺失或设置无效时安全回退。

### Modified Capabilities

无。

## Impact

- 影响 Options 页面中的外观设置、共享偏好校验与本地存储、Content Script 的译文样式变量和设置变更同步。
- 影响译文容器及行内 `code`、`kbd` 的 CSS，但不改变 Provider 请求、翻译缓存键、原文 DOM 或网站权限。
- 增加字体偏好、消息边界、实时更新、CSS 隔离和回退行为测试；不增加运行时依赖，也不打包或远程下载 Maple Mono 字体文件。
