## MODIFIED Requirements

### Requirement: 手动控制当前页翻译
扩展 SHALL 允许用户从 Popup 或页面内悬浮按钮对当前活动的普通 HTTP 或 HTTPS 页面开始翻译，并 SHALL 显示当前 session 的排队、翻译完成和失败数量。空闲状态下单击悬浮按钮 MUST 直接开始翻译且保持面板折叠；翻译中、已停止或已完成状态下再次单击悬浮按钮 MUST 停止当前工作并恢复原文。

#### Scenario: 从空闲悬浮按钮开始翻译
- **WHEN** 用户已选择可用 provider 并单击空闲状态的悬浮按钮
- **THEN** 扩展在当前标签页建立新的翻译 session、立即显示候选块 loading 并保持状态面板折叠

#### Scenario: 从 Popup 开始当前页翻译
- **WHEN** 用户已选择可用 provider 并在 Popup 点击开始翻译
- **THEN** 扩展在当前标签页建立新的翻译 session、提取候选块并显示进度

#### Scenario: 翻译状态下再次单击悬浮按钮
- **WHEN** 当前 session 正在翻译、已停止、已完成或部分失败且用户单击悬浮按钮
- **THEN** 扩展取消仍在进行的任务、移除已插入的译文并恢复原文，而不创建重复 session

#### Scenario: 缺少可用 provider
- **WHEN** 用户在没有已授权可用 provider 时点击开始翻译
- **THEN** 扩展不修改页面，并引导用户打开配置页

#### Scenario: 页面不允许注入
- **WHEN** 当前页是浏览器内部页面或其他禁止 Content Script 注入的页面
- **THEN** 扩展显示该页面无法翻译，而不报告虚假成功

## ADDED Requirements

### Requirement: 可选持久页面入口与权限降级
扩展 SHALL 在用户明确授权网站访问后，使用动态注册且可跨浏览器会话保留的 Content Script 在获准的 HTTP 或 HTTPS 页面自动显示悬浮按钮。授权 MUST 是可选且可撤销的；未授权、拒绝或撤销后，扩展 MUST 保留由 `activeTab` 用户操作触发的当前页注入方式，并 MUST NOT 尝试注入浏览器内部页、扩展商店或其他受限页面。

#### Scenario: 用户授予网站访问
- **WHEN** 用户在扩展配置界面明确同意支持页面内一键入口所需的网站访问
- **THEN** 扩展注册持久 Content Script，后续打开获准网页时自动显示悬浮按钮

#### Scenario: 重启浏览器后访问普通网页
- **WHEN** 用户此前已授权且重启浏览器后打开获准的普通 HTTP 或 HTTPS 页面
- **THEN** 悬浮按钮无需先打开 Popup 即可显示且不重复注入

#### Scenario: 用户拒绝或撤销网站访问
- **WHEN** 用户拒绝授权或撤销已有网站访问权限
- **THEN** 扩展移除对应动态注册并继续允许用户通过扩展按钮以 `activeTab` 模式注入当前页

#### Scenario: 打开受限页面
- **WHEN** 用户打开浏览器内部页、扩展商店或其他禁止注入的页面
- **THEN** 扩展不显示悬浮按钮、不发起注入并在用户操作时给出明确限制说明

### Requirement: 选择主要内容或整个页面
扩展 SHALL 提供“主要内容”和“整个页面”两种翻译范围，并 MUST 默认选择主要内容。主要内容模式 SHALL 优先翻译 `article`、`main` 或可识别的正文容器，并跳过导航、页脚和侧栏；整个页面模式 SHALL 使用既有安全排除规则处理全部合格候选块。

#### Scenario: 默认翻译文章正文
- **WHEN** 用户未修改翻译范围并在含正文、导航和侧栏的文章页开始翻译
- **THEN** 扩展翻译主要正文且不提交已识别的导航、页脚和侧栏文本

#### Scenario: 用户选择整个页面
- **WHEN** 用户将翻译范围切换为整个页面后开始翻译
- **THEN** 扩展处理页面内全部符合安全提取规则的候选块

#### Scenario: 无法可靠识别主要内容
- **WHEN** 主要内容模式无法找到可信正文容器
- **THEN** 扩展回退到当前视口优先的合格候选块并在状态中记录范围回退

### Requirement: 页面快捷键控制翻译
扩展 SHALL 提供可由浏览器扩展快捷键机制管理的翻译控制：一个命令用于开始翻译或在译文与原文之间切换，另一个命令用于以整个页面范围开始翻译。快捷键 MUST 复用同一 session 状态机，不得绕过 provider、权限、取消或安全渲染检查。

#### Scenario: 使用默认切换快捷键
- **WHEN** 用户在普通网页触发翻译切换命令且当前没有译文
- **THEN** 扩展按主要内容范围启动翻译

#### Scenario: 已有译文时触发切换
- **WHEN** 当前页已有该扩展插入的译文且用户触发翻译切换命令
- **THEN** 扩展在保留缓存的前提下恢复原文，再次触发时可重新显示或翻译

#### Scenario: 使用整个页面快捷键
- **WHEN** 用户在普通网页触发整个页面翻译命令
- **THEN** 扩展按整个页面范围启动或重启当前页翻译 session
