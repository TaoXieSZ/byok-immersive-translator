## Why

整页翻译适合持续阅读，但用户遇到单个陌生词句时仍需要启动整页 session 或离开当前页面查询，打断阅读且产生不必要的 API 消耗。段落魔法镜提供一个明确触发、轻量且保留上下文的划词翻译入口，让 BYOK 扩展覆盖即时理解场景而不扩大凭据和页面数据边界。

## What Changes

- 用户在普通网页中选中有效文本后看到一个贴近选区的翻译按钮，只有点击按钮才会发起远端请求。
- 点击按钮后打开独立的 Shadow DOM 翻译卡片，立即显示 loading，并在 Provider 支持时流式展示译文。
- 仅展示和复制所选文本的译文；请求可携带有长度上限的所在语义段落作为消歧上下文。
- 卡片提供复制译文、复制双语、重新翻译和关闭操作；新选区、关闭、`Esc` 或页面离开会使旧请求失效。
- 选区请求使用独立且包含上下文哈希的缓存维度，缓存结果不保存上下文明文；重新翻译显式绕过缓存。
- 魔法镜与整页翻译 session 相互隔离，并排除输入控件、可编辑区域、代码块以及扩展生成的译文。
- Content Script 不能指定 Provider、Base URL、Token、请求头或模型覆盖，现有 Service Worker 凭据边界保持不变。

## Capabilities

### New Capabilities

- `paragraph-magic-lens`: 定义划词入口、受限上下文翻译卡片、缓存与重新翻译、生命周期隔离以及安全和可访问性交互。

### Modified Capabilities

无。

## Impact

- Content Script：增加选区识别、锚点定位、卡片控制器以及与整页 session 隔离的临时请求生命周期。
- Service Worker：增加严格校验的单选区流式翻译与取消路径，继续只使用当前已保存 Provider。
- 共享协议与缓存：增加选区消息、受限上下文字段、选区缓存键和显式绕过缓存语义。
- 页面样式：增加封装在 Shadow DOM 内的按钮、loading、结果、错误及复制反馈状态。
- 测试：覆盖选区过滤、上下文最小化、消息安全、缓存隔离、迟到响应、卡片定位与整页翻译共存。
- 不引入运行时依赖，不新增常驻远端服务，也不改变现有 Provider 凭据存储方式。
